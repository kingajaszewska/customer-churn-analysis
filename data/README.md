# Dataset

The analysis expects a file named `Telco.csv` in this directory.

The supplied course file matches the schema of Kaggle's [Churn in Telecom's dataset](https://www.kaggle.com/datasets/becksddf/churn-in-telecoms-dataset): 3,333 customer records and 21 columns.

The Kaggle source currently lists the license as unknown. For that reason, the raw file is used locally to execute the notebook but is not redistributed in the public repository.
